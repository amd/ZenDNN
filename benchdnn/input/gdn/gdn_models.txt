# GDN (Gated DeltaNet) model shapes for --op=gdn.
# Used with: ./benchdnn --op=gdn --input_file=<this_file> [--iters=N]
#            [--warmup_iters=N] [--num_threads=N] [--cache_mode=hot]
#
# Format per line (CSV, '#' comments and blank lines ignored):
#   model, num_k_heads, num_v_heads, head_k_dim, head_v_dim, conv_width,
#   num_decodes, num_prefills, prefill_len
#   [, iters, warmup_iters, src_dt, state_dt, has_initial_state,
#      state_layout, fused_norm, prefill_algo, kernel, num_threads]
#
# Each line is one gdn_direct call over a vLLM batch: num_decodes
# single-token decodes first, then num_prefills prefills of prefill_len
# tokens. Defaults: bf16 activations, f32 SSM state (mamba_ssm_dtype), kv
# state layout, prefills continuing from their slots, no fused norm,
# automatic prefill algorithm and kernel, all OpenMP threads.
# --src_dt=<f32|bf16|f16> and --state_dt=<...> change the types of lines
# that leave src_dt / state_dt empty, e.g. --src_dt=f16 runs every model
# row with fp16 activations.
#
# Shapes are linear_num_key_heads, linear_num_value_heads,
# linear_key_head_dim, linear_value_head_dim and linear_conv_kernel_dim from
# each model's config.json (text_config). Timing is cold-cache by default.
